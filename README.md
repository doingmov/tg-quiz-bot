# Квиз-бот для музея

Бот проводит викторину по истории и помогает отобрать кандидатов на стажировку: вопросы с единственным правильным ответом, автоматическая проверка и кнопочное меню. Работает в Telegram и ВКонтакте.

## Боты

- Telegram: https://t.me/quizquestions1_bot
- ВКонтакте: https://vk.com/club242626917

Напишите боту `/start` (в ВКонтакте `start`), затем нажмите «Новый вопрос».

## Возможности

- «Новый вопрос» присылает случайный вопрос викторины.
- Ответ проверяется автоматически: регистр, лишние пробелы и знаки препинания не важны, пояснения в скобках и после точки учитывать не нужно.
- «Сдаться» показывает правильный ответ и сразу задаёт следующий вопрос.
- Вопрос, заданный пользователю, хранится в Redis, поэтому бот помнит его между сообщениями и после перезапуска.

## Как запустить

1. Установите Python 3.11 и зависимости:

   ```bash
   pip install -r requirements.txt
   ```

   Библиотека `python-telegram-bot` версии 13.x не работает на Python 3.12 и новее.

2. Скачайте [архив с вопросами](https://dvmn.org/media/modules_dist/quiz-questions.zip) и распакуйте его в папку `quiz-questions` рядом со скриптами:

   ```bash
   mkdir quiz-questions
   unzip quiz-questions.zip -d quiz-questions
   ```

3. Создайте файл `.env` в корне проекта:

   ```
   TELEGRAM_TOKEN=токен бота из BotFather
   VK_TOKEN=ключ доступа сообщества ВКонтакте
   REDIS_HOST=адрес базы Redis
   REDIS_PORT=порт базы Redis
   REDIS_PASSWORD=пароль Redis (если он есть)
   ```

4. Запустите ботов (каждого в своём процессе):

   ```bash
   python tg_bot.py
   python vk_bot.py
   ```

## Переменные окружения

| Переменная       | Описание                                              |
|------------------|-------------------------------------------------------|
| `TELEGRAM_TOKEN` | Токен Telegram-бота, выдаётся в @BotFather            |
| `VK_TOKEN`       | Ключ доступа сообщества ВКонтакте (права на сообщения) |
| `REDIS_HOST`     | Адрес сервера Redis                                   |
| `REDIS_PORT`     | Порт сервера Redis                                    |
| `REDIS_PASSWORD` | Пароль Redis, необязательно                           |

## Структура проекта

- `tg_bot.py` — бот для Telegram (на `ConversationHandler`).
- `vk_bot.py` — бот для ВКонтакте (на Long Poll).
- `quiz_utils.py` — общий код: загрузка вопросов и проверка ответов.

## Деплой

Боты запущены на сервере Timeweb Cloud как службы `systemd` (`quiz-tg` и `quiz-vk`). Секреты передаются через файл `.env` на сервере, в репозиторий они не попадают.

Обновление на сервере:

```bash
cd /opt/tg-quiz-bot
git pull
systemctl restart quiz-tg quiz-vk
```
